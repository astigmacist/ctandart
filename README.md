# CtandART ERP

Web ERP для рекламно-производственной компании CtandART.

## Что входит в контур

- CRM клиентов.
- Заказы как главный объект учета.
- Производственные задачи: дизайн, печать, сборка, монтаж.
- Один физический склад с учетными зонами: главный склад, производство/офис, магазин.
- Раздельная видимость остатков по ролям.
- Складские движения через завсклад и аудит.
- Оплаты, долги, кассы офиса и магазина.
- Бонусная система клиентов: Silver, Gold, VIP, бонусный баланс, аванс.
- Геймификация сотрудников и команд.
- Дневной отчет руководителя.
- Антикоррупционный аудит.

Бухгалтерия не входит в текущий контур и остается отдельно.

## Структура

```text
apps/api   FastAPI backend
apps/web   Vite React frontend
docs       продуктовая и техническая архитектура
infra      docker compose и будущая инфраструктура
```

## Локальный запуск

Backend:

```bash
npm run api:dev
```

Frontend:

```bash
npm run web:dev
```

PostgreSQL/Redis, если установлен Docker:

```bash
docker compose -f infra/docker-compose.yml up -d
```

Локально backend по умолчанию работает на SQLite-файле `apps/api/ctandart_dev.db`, чтобы можно было разрабатывать без Docker. На хостинге используем PostgreSQL.
