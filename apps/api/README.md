# CtandART ERP API

Backend для web ERP CtandART.

## Локальный запуск

```bash
cd apps/api
uvicorn app.main:app --reload
```

## Главные правила домена

- Заказ клиента - центральная сущность.
- Склад физически может быть один, но учетно разделен на зоны: главный склад, производство/офис, магазин.
- Производство и магазин не видят остатки друг друга.
- Критические операции не удаляются, а отменяются обратной операцией.
- Все изменения цены, оплаты, бонусов и складских движений пишутся в аудит.
- Бухгалтерский учет не входит в MVP; только управленческий учет.
