# Этап 1 - авторизация, роли, меню

## Что реализовано

- Публичной регистрации нет.
- Вход только по учетной записи, которую создал руководитель или администратор.
- Backend создает стартовые учетные записи по ролям.
- Owner/admin могут создавать новые учетные записи через интерфейс.
- Меню и рабочий процесс зависят от роли.
- Роль дизайнера уже видит другой интерфейс: только свои задачи, заказы и рейтинг.
- Все будущие ERP-разделы сохранены в структуре, чтобы включать их по этапам.

## Роли

1. Owner - полный доступ.
2. Admin - пользователи, настройки, справочники, аудит.
3. Warehouse manager - склад, перемещения, ревизия.
4. Manager - клиенты, заказы, оплаты клиента, бонусы.
5. Designer - свои задачи, макеты, согласование.
6. Production - производственная очередь, техзадание, факт работ.
7. Installer - монтаж, фотоотчет, чек-лист.
8. Store cashier - магазин, касса магазина, остатки магазина.
9. Finance - оплаты, долги, управленческие отчеты.
10. Client - будущий клиентский кабинет.

## Локальная база

Локально используется SQLite:

```text
apps/api/ctandart_dev.db
```

На хостинге будет PostgreSQL.
